Личный сайт со ссылками на социальные сети.

## Файлы проекта

- `index.html` - главная страница
- `styles.css` - стили
- `background.gif` - анимированный фон
- `avatar.jpg` - аватарка

## Как опубликовать

### Вариант 1: GitHub Pages
1. Создай репозиторий на GitHub
2. Загрузи все файлы
3. Settings → Pages → Source: main branch
4. Сайт будет доступен по адресу: `https://username.github.io/repo-name`

### Вариант 2: Netlify (проще всего)
1. Зайди на https://netlify.com
2. Перетащи папку с проектом
3. Получишь ссылку автоматически

### Вариант 3: Vercel
1. Зайди на https://vercel.com
2. Импортируй проект
